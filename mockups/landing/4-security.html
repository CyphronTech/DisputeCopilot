Security posture

The audit isn't a promise. It's a query you can run yourself.

A merchant's security review looks at this connector once, at setup — not at every case, because the model has no way to change it.

  • Dedicated database identity with SELECT only, on one view.
  • Read-only transaction mode, a row limit, and a query timeout.
  • Query template version and row count logged, not the payload.
  • Uploaded documents are treated as data, never as instructions.
