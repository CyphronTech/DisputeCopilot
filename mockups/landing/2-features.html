What's deliberately missing is the point.

No SQL tool. No unbounded chat history. No recommendation without a citation. The constraints are the product, not an afterthought.

Connector

No SQL access for the model, ever

The LLM never receives a database credential, a JDBC handle, or a tool to write queries. One statement runs before the first model call, and it's the same statement every time.

-- the only query DisputeCopilot runs
SELECT * FROM dispute_case_view
WHERE order_id = :orderId LIMIT 1;
Retrieval

Effective-dated policy matching

Chunks are filtered by document type and order date, in your configured time zone, before similarity search runs at all.

Validation

Citations checked, not trusted

Every quoted excerpt is confirmed against the stored chunk. Unverifiable claims are rejected, not softened.

Audit

Every action, timestamped

Queries, model calls, approvals, and content hashes are logged as they happen — an append-only record, not a summary.

Deployment

Runs on your infrastructure

Docker Compose, your database, your model provider key. We never operate a hosted copy of your data.
